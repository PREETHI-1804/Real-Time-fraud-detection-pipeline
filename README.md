# Real-Time Financial Fraud Detection Pipeline

An end-to-end streaming data and machine learning pipeline designed to ingest continuous financial transaction streams, engineer predictive features, and detect real-time transaction anomalies with high accuracy using Python, Scikit-Learn, and XGBoost.

## Project Overview

- Designed and deployed a streaming data pipeline using Apache Kafka to process continuous financial transaction streams.
- Trained and tuned a machine learning classification model using Scikit-Learn to detect real-time transaction anomalies with high accuracy.
- Engineered complex data preprocessing and feature extraction logic using Pandas, reducing data noise and optimizing detection performance.
- Developed structured analytics dashboards for live transaction monitoring and risk visual reporting.

## Technical Stack

- Python
- Scikit-Learn
- Apache Kafka
- Pandas
- SQL
